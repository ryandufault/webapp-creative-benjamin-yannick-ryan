App header : Le menu où l'utilisateur arrive quand il ouvre le site, vous pouvez commencer, continuer, sauvegarder et modifier les options

StatsBar : Barre qui display des statistiques/métriques

StatIndicator : Barre représentante de chaque métrique différente

Chater View : Vue global du chapitre, regroupe choice panel et narrative text

Choice pannel : regroupe les choix

Ending screen : Écran de fin avec récapitulatif

Choice History : Récapitulatif des choix faits par le joueur

StatsSummary : Statistiques des métriques finales lors de la fin obtenue

Modal : Le menu quand t'appuis sur escape

Narrative text : Texte de narration

Save slot manager : Configuration des sauvegardes
